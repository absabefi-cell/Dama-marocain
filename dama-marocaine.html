DAMA • MAROC

À toi de jouer.

Une partie, deux joueurs. Choisis l’ordinateur, le même téléphone ou une connexion directe avec un ami.

Connexion entre amis

Ouvrez le même lien GitHub Pages, idéalement dans Chrome et sur le même Wi-Fi. Gardez les pages ouvertes pendant l’échange.

Pas encore connecté.

Le créateur joue les blancs. L’ami joue les noirs. Aucun compte Firebase. Un service STUN public aide à établir la connexion ; certains réseaux nécessitent un relais TURN, absent de cette version. Si la connexion échoue, essayez le même Wi-Fi puis recréez les codes.

Règles de cette version

Les blancs commencent. Un pion avance en diagonale et capture uniquement vers l’avant. La prise est obligatoire et les prises successives doivent être terminées avec la même pièce. La dame se déplace sur plusieurs cases en diagonale et peut prendre dans les deux sens, si une case libre existe derrière la pièce adverse. Plusieurs parcours possibles : choisis librement, sans obligation de prendre le maximum. Promotion en fin de tour. Ces règles peuvent varier selon les habitudes de jeu.

Pour publier : nomme ce fichier index.html dans ton dépôt GitHub Pages. Les deux joueurs ouvrent cette même adresse. Le code court 9897 n’est pas utilisé : l’invitation et la réponse contiennent les informations réelles de connexion.
